# 🎓 Daily English — Ваш личный голосовой ИИ-учитель английского

**«Daily English»** — это прогрессивное веб-приложение (PWA), созданное специально для русско- и украиноязычных взрослых учеников с начальным уровнем **A0–A1 (полный новичок)**.

Приложение спроектировано по принципу **Voice-First**: основной фокус на живую речь, слуховое восприятие и тренировку произношения с непрерывной поддержкой на русском языке.

---

## 🌟 Ключевые возможности

### 1. 🤖 Экран «Учитель» (Главный)
- **Большая кнопка микрофона** — говорите голосом, как с живым репетитором. Текстовый ввод доступен для тихих мест.
- **Сверхпростая речь учителя**: предложения строго из **3–7 слов**, базовая лексика, ровно **один вопрос за раз**.
- **Двуязычная поддержка**: если вы ответили по-русски — учитель поймёт, покажет, как сказать это по-английски, и предложит повторить вслух.
- **Мягкие исправления**: максимум 1 главная ошибка за сообщение, доброе объяснение на русском и тёплая похвала.
- **Интерактивные слова**: нажмите на любое английское слово в сообщении, чтобы мгновенно увидеть перевод, транскрипцию русскими буквами и кнопку «⭐ Сохранить в словарь».
- **Кнопки озвучки**: обычная скорость (0.85x) и замедленная (0.6x) для идеальной разборчивости.
- **Режим «Повтори за мной»**: произносите фразы в микрофон — система сравнит вашу речь с образцом, подсветит слова цветом (зелёный/жёлтый/красный) и покажет % совпадения.

### 2. 📅 Экран «Сегодня» (Ежедневный урок 10–15 минут)
- **Шаг 1**: 5 полезных фраз по теме дня с переводом, транскрипцией и аудио.
- **Шаг 2**: Тренировка произношения всех 5 фраз с валидацией через микрофон.
- **Шаг 3**: Мини-диалог с учителем по теме урока (3 быстрых обмена репликами).
- **12 структурированных тем от быта к работе**:
  1. Знакомство и о себе
  2. Цифры и цены
  3. Семья
  4. Еда и кафе
  5. Магазин
  6. Дорога и транспорт
  7. Время и дни
  8. Отель
  9. Аэропорт
  10. Здоровье
  11. Телефонный разговор
  12. Простые рабочие разговоры

### 3. 📖 Экран «Слова» (Интервальное повторение SM-2)
- **Карточки памяти (SuperMemo-2)**: кнопки «Снова», «Трудно», «Хорошо», «Легко» автоматически вычисляют оптимальный интервал повторения.
- **Режим «На слух»**: слушаете произношение слова и выбираете правильный перевод из 4 вариантов.
- **Словарь**: список всех сохранённых слов с озвучкой в один клик.

### 4. 📈 Экран «Прогресс»
- Подсчёт серии дней подряд (Streak 🔥).
- Минуты разговорной практики и количество выученных слов.
- Раздел «Мои частые ошибки»: сохраняет подсказки учителя для повторения.
- PWA-напоминания о ежедневном уроке.

## 🛠️ Стек технологий

- **Фреймворк**: Next.js 15 (App Router) + React 19 + TypeScript
- **Стилизация**: Tailwind CSS (mobile-first, thumb-friendly интерфейс)
- **ИИ-модель**: Google Gemini API (`gemini-2.5-flash`) через защищённый серверный роут `/api/teacher` (ключ никогда не попадает в браузер)
- **Голос**: Web Speech API (`SpeechRecognition` en-US + `SpeechSynthesis` en-US) с поддержкой Gemini TTS
- **Хранение данных**: Локальная база **IndexedDB** через паттерн `StorageAdapter` (полная автономность, быстрота, готовность к мгновенному подключению Supabase)
- **PWA**: `manifest.json`, Service Worker, возможность установки на iPhone и Android как нативное приложение

## 🔑 Как бесплатно получить ключ Gemini API

1. Перейдите на сайт **[Google AI Studio](https://aistudio.google.com/)**.
2. Войдите под своим Google-аккаунтом.
3. Нажмите синюю кнопку **«Get API key»** (в левом верхнем углу).
4. Нажмите **«Create API key»** и скопируйте созданный ключ (строка вида `AIzaSy...`).
   > *Примечание: Бесплатного лимита Gemini API более чем достаточно для ежедневных занятий.*

## 🚀 Быстрый запуск на компьютере

### 1. Перейдите в папку проекта:
```bash
cd "/Users/davidsittarov/Desktop/Учитель-Английского"
```

### 2. Создайте файл `.env.local`:
Откройте файл `.env.local` и укажите ваш ключ:
```env
GEMINI_API_KEY=ваш_ключ_от_Google_AI_Studio
```

*(Если ключ ещё не указан, приложение автоматически запустится в демонстрационном режиме с умными ответами).*

### 3. Запустите сервер разработки:
```bash
npm run dev
```

Откройте в браузере: **`http://localhost:3000`** (рекомендуется браузер Google Chrome).

## 📱 Как установить на телефон (PWA)

### Вариант A: Локально через Wi-Fi
1. Убедитесь, что телефон и компьютер подключены к одной Wi-Fi сети.
2. В терминале при запуске `npm run dev` отобразится локальный сетевой адрес, например:
   `http://192.168.1.100:3000`
3. Откройте этот адрес в браузере телефона.

### Вариант B: Деплой на Vercel (Рекомендуется для постоянного использования)
После деплоя у вас будет собственный HTTPS-адрес (например, `https://daily-english.vercel.app`), с которого работают все микрофонные API и PWA:

1. **iPhone (Safari)**:
   - Откройте ссылку на приложение в Safari.
   - Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх внизу экрана ⎋).
   - Прокрутите вниз и выберите **«На экран „Домой“»** (Add to Home Screen).
   - Нажмите «Добавить». Теперь приложение запускается как нативное без рамок браузера!

2. **Android (Chrome)**:
   - Откройте ссылку в Chrome.
   - Нажмите три точки в правом верхнем углу ⋮.
   - Выберите **«Установить приложение»** или **«Добавить на главный экран»**.

## ☁️ Деплой на Vercel

### Способ 1: Через веб-интерфейс Vercel (в 2 клика)
1. Загрузите проект в свой репозиторий на GitHub.
2. Зайдите на **[vercel.com](https://vercel.com)** и нажмите **«Add New...» -> «Project»**.
3. Выберите ваш репозиторий с Daily English.
4. В разделе **Environment Variables** добавьте:
   - Имя: `GEMINI_API_KEY`
   - Значение: *ваш ключ от Google AI Studio*
5. Нажмите **«Deploy»**. Через 1 минуту приложение будет доступно по всему миру!

### Способ 2: Через терминал (Vercel CLI)
```bash
npm install -g vercel
vercel
```
При запросе переменных окружения укажите `GEMINI_API_KEY`.
